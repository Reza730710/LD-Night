LD NIGHT — پروژهٔ بازی اندروید
================================

این ZIP شامل یک بازی بلوکی آفلاین قابل اجرا در مرورگر و پروژهٔ Android WebView است.
برای اجرا بدون کامپیوتر: فایل index.html را با مرورگر موبایل باز کنید، یا از روش ساخت APK ابری پایین استفاده کنید.

قابلیت‌های پیاده‌سازی‌شده در این نسخه:
- منوی فارسی، مقدمه قابل رد کردن و گویندگی فارسی در مرورگرهای پشتیبان
- دنیای بلوکی ایزومتریک با انواع بلوک، حرکت لمسی، کندن و گذاشتن بلوک
- حالت خلاقانه/بقا، جان و غذا، چرخه روز/غروب/شب
- کوله‌پشتی، مواد اولیه و میز ساخت
- تنظیم نام بازیکن تا ۲۰۰ نویسه، اندازه دکمه‌ها، کیفیت و فهرست زبان‌ها
- افسون نمایشی ابزار تا سطح ۱۰۰۰ با عدد رومی
- گاراژ نمایشی خودروها، تجهیزات فانتزی و لابی محلی با کد اتاق
- ذخیرهٔ محلی جهان در مرورگر
- پروژه Android WebView و گردش‌کار GitHub Actions برای ساخت APK آزمایشی

محدودیت‌های مهم:
این نسخه «بازی کامل در مقیاس Minecraft» نیست و APK از قبل کامپایل یا روی دستگاه آزمایش نشده است.
چندنفرهٔ واقعی، سرور آنلاین، جهان سه‌بعدی واقعی، فیزیک/رانندگی واقعی، هوش مصنوعی دشمنان، سیستم کامل مود و شیدر و تمام محتواهای یک بازی تجاری نیازمند توسعهٔ بیشتر هستند. لابی، خودروها و تجهیزات در این نسخه ساده/نمایشی‌اند. این موارد را کامل‌شده فرض نکنید.

ساخت APK با گوشی:
1) این ZIP را از حالت فشرده خارج کنید.
2) در GitHub یک مخزن جدید بسازید و فایل‌های داخل پوشه را در آن آپلود کنید.
3) به زبانه Actions بروید و workflow با نام Android APK را اجرا کنید.
4) پس از پایان موفق، از بخش Artifacts فایل LD-Night-debug-apk را دریافت کنید و APK داخل آن را روی گوشی نصب کنید.
5) اگر GitHub درباره مجوزها یا تأیید حساب چیزی خواست، همان دستورهای رسمی خودش را دنبال کنید.

برای نصب مستقیم APK آماده لازم است پروژه در محیط Android SDK ساخته و آزمایش شود؛ این ZIP به‌تنهایی APK نصب‌شدنی نیست.
